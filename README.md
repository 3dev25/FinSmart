# FinSmart

Русскоязычный Telegram-бот для финансовых расчётов. Валюта по умолчанию — RUB; все банковские ставки и условия вводит сам пользователь.

## Возможности

- Досрочное погашение: сравнение сокращения срока и уменьшения платежа.
- Рефинансирование: сравнение кредитов с учётом комиссий и страховки.
- Кэшбэк: импорт CSV истории расходов и расчёт по пользовательскому правилу категории. Каталог карт и выдуманные предложения банков не используются.

## Локальный запуск

Требуются Python 3.11+ и PostgreSQL 14+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN и DATABASE_URL
python -m finsmart
```

## Render

`render.yaml` описывает Docker Background Worker для Telegram long polling и PostgreSQL в регионе Frankfurt. Создайте Blueprint из репозитория, затем добавьте секрет `BOT_TOKEN` в Environment сервиса Worker. `DATABASE_URL` связывается через Blueprint.

## Команды

`/start`, `/prepay`, `/refinance`, `/cashback`, `/help`, `/privacy`, `/delete_me`.

## CSV

UTF-8/UTF-8 BOM; разделители запятая, точка с запятой или табуляция. Обязательные столбцы — сумма (`amount`/`сумма`) и категория (`category`/`категория`). Не загружайте банковские реквизиты.

## Ограничения

Расчёты ориентировочные: реальный банк может начислять проценты по дням и применять собственные правила досрочного погашения. Без MCC нельзя гарантировать учёт всех исключений кэшбэка.

Не коммитьте `.env`, токены, пароли, CVV и полные номера карт. Тесты запускаются командой `pytest`.
